Esfera de átomos

Pulsa «Activar cámara» para controlarlo con las manos.

  • Mover la mano → gira la esfera
  • Pinza pulgar + índice → acerca / aleja (zoom)
  • Abrir / cerrar los otros dedos → separa los átomos / vuelve a juntar
  • Dos manos → separarlas o juntarlas hace zoom
  • Sin cámara: arrastra con el ratón, rueda = zoom, Espacio = dispersar
